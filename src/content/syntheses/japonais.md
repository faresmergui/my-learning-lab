## Les hiragana

| | a | i | u | e | o |
| --- | --- | --- | --- | --- | --- |
| — | あ | い | う | え | お |
| k | か | き | く | け | こ |
| s | さ | し *shi* | す | せ | そ |
| t | た | ち *chi* | つ *tsu* | て | と |
| n | な | に | ぬ | ね | の |
| h | は | ひ | ふ *fu* | へ | ほ |
| m | ま | み | む | め | も |
| y | や | | ゆ | | よ |
| r | ら | り | る | れ | ろ |
| w | わ | | | | を *o* |
| n | ん | | | | |

**Dakuten** (゛) : k → g, s → z, t → d, h → b. **Handakuten** (゜) : h → p. が, ざ, だ, ば, ぱ…
**Combinaisons** avec un petit ゃ ゅ ょ : きゃ *kya*, しゅ *shu*, ちょ *cho*. **Petit っ** : double la consonne suivante, きって *kitte*.

Les katakana servent aux mots étrangers, aux noms étrangers et aux onomatopées. Le trait **ー** allonge la voyelle : コーヒー (café). Pièges : シ / ツ et ソ / ン se distinguent par le sens des traits.

## La phrase de base

- Ordre **sujet, compléments, verbe** : le verbe est toujours à la fin.
- **A は B です** : A est B. Négatif : B じゃないです (ou ではありません). Passé : B でした.
- Question : on ajoute **か** à la fin, sans changer l'ordre.
- Le sujet est souvent **omis** quand il est évident.

## Les particules

| Particule | Rôle | Exemple |
| --- | --- | --- |
| は (wa) | thème, contraste | わたしは がくせいです |
| が | sujet, information nouvelle, goûts et capacités | ねこが すきです |
| を (o) | objet direct | コーヒーを のみます |
| に | moment précis, destination, lieu d'existence, destinataire | ろくじに / がっこうに いきます |
| で | lieu de l'action, moyen | としょかんで べんきょうします / バスで |
| へ (e) | direction | にほんへ いきます |
| と | avec, et (liste complète), citation | ともだちと |
| や | et (liste non exhaustive) | パンや たまご |
| も | aussi | わたしも |
| の | possession, lien entre noms | わたしの ほん |
| から / まで | de… jusqu'à | くじから ごじまで |
| か / ね / よ | question / accord attendu / information apportée | そうですね |

Règle express : **で** pour une action, **に** pour une existence ou une destination. Pas de **に** après きょう, あした, まいにち.

## Le tableau des conjugaisons

| Dictionnaire | ます | ない | た | て | conditionnel ば | potentiel | volitif |
| --- | --- | --- | --- | --- | --- | --- | --- |
| たべる | たべます | たべない | たべた | たべて | たべれば | たべられる | たべよう |
| のむ | のみます | のまない | のんだ | のんで | のめば | のめる | のもう |
| かく | かきます | かかない | かいた | かいて | かけば | かける | かこう |
| いく | いきます | いかない | **いった** | **いって** | いけば | いける | いこう |
| する | します | しない | した | して | すれば | できる | しよう |
| くる | きます | こない | きた | きて | くれば | こられる | こよう |

**Forme en て, groupe 1** : う・つ・る → って · む・ぶ・ぬ → んで · く → いて · ぐ → いで · す → して. La forme en た suit les mêmes règles.
**ない, groupe 1** : la dernière syllabe passe en colonne **a**, う devient わ : かう → かわない.

## Les adjectifs

| | Adjectif en い (たかい) | Adjectif en な (しずか) |
| --- | --- | --- |
| Présent | たかいです | しずかです |
| Négatif | たかくないです | しずかじゃないです |
| Passé | たかかったです | しずかでした |
| Passé négatif | たかくなかったです | しずかじゃなかったです |
| Devant un nom | たかい やま | しずかな へや |
| Forme en て | たかくて | しずかで |
| Adverbe | たかく | しずかに |

Pièges : いい se conjugue sur よい (よくない, よかった). きれい, ゆうめい, きらい sont des adjectifs en **な**.

## Les formes utiles du N5 au N3

| Forme | Sens | Exemple |
| --- | --- | --- |
| radical + たい | vouloir faire | いきたいです |
| て + ください | s'il te plaît, fais… | まってください |
| て + いる | action en cours, état résultant | たべています / けっこんしています |
| て + もいい | permission | すわってもいいですか |
| て + はいけない | interdiction | ここで たべてはいけません |
| ない + ければならない | obligation | いかなければなりません |
| dictionnaire + ことができる | capacité | およぐことができます |
| た + ことがある | expérience | にほんへ いったことがあります |
| つもり / volitif + とおもう | intention | いこうとおもいます |

## Les conditionnels

| Forme | Usage | Exemple |
| --- | --- | --- |
| と | conséquence automatique, chemin | ボタンを おすと、ドアが あきます |
| ば | condition générale, conseil | れんしゅうすれば、うまくなります |
| たら | si, une fois que (le plus polyvalent) | あめが ふったら、いきません |
| なら | si c'est le cas (ce que tu dis) | パソコンを かうなら、これが いい |

## Donner et recevoir

| Verbe | Direction | Avec une action |
| --- | --- | --- |
| あげる | de moi vers les autres | ～てあげる : faire pour quelqu'un |
| くれる | des autres vers moi | ～てくれる : quelqu'un fait pour moi |
| もらう | je reçois de quelqu'un (に) | ～てもらう : obtenir que quelqu'un fasse |

## Apparence et ouï-dire

| Forme | Sens | Exemple |
| --- | --- | --- |
| radical + そう | on dirait (à la vue) | おいしそうです |
| neutre + そう | il paraît que (ouï-dire) | あめが ふるそうです |
| neutre + よう / みたい | il semble que (déduction) | だれも いないようです |
| neutre + らしい | apparemment (info indirecte) | かれは びょうきらしいです |

| Forme | Groupe 1 (かく) | Groupe 2 (たべる) | する / くる | Sens |

| Passif | かかれる | たべられる | される / こられる | subir, être fait |

## Le keigo

| Verbe | Respectueux (l'autre agit) | Humble (je agis) |
| --- | --- | --- |
| いる | いらっしゃる | おる |
| いく / くる | いらっしゃる | まいる |
| いう | おっしゃる | もうす |
| する | なさる | いたす |
| たべる / のむ | めしあがる | いただく |
| みる | ごらんになる | はいけんする |
| しっている | ごぞんじだ | ぞんじている |

Forme générale : respectueux **お + radical + になる** (おまちになる), humble **お + radical + する** (おまちする).

## Nombres et dates irréguliers

- Heures : 4 h *よじ*, 7 h *しちじ*, 9 h *くじ*. Minutes : 1 *いっぷん*, 3 *さんぷん*, 6 *ろっぷん*, 10 *じゅっぷん*.
- Jours du mois : 1 *ついたち*, 2 *ふつか*, 3 *みっか*, 4 *よっか*, 5 *いつか*, 6 *むいか*, 7 *なのか*, 8 *ようか*, 9 *ここのか*, 10 *とおか*, 14 *じゅうよっか*, 20 *はつか*, 24 *にじゅうよっか*.
- Mois : avril *しがつ*, juillet *しちがつ*, septembre *くがつ*.
- Centaines : 300 *さんびゃく*, 600 *ろっぴゃく*, 800 *はっぴゃく*. Milliers : 3 000 *さんぜん*, 8 000 *はっせん*.
- On compte par **万** (10 000) : 100 000 = 十万, 1 000 000 = 百万.
