C'est la question qui revient le plus chez les débutants. La réponse complète prend des années, mais quatre règles couvrent l'essentiel.

## は : le thème

は annonce **de quoi on parle**, puis la suite le commente. Il se prononce *wa*.

わたしは がくせいです。 *Moi, je suis étudiant.*

## が : le sujet

| Situation | Exemple |
| --- | --- |
| mot interrogatif sujet | だれが きましたか。 *Qui est venu ?* |
| ce qui existe | にわに ねこが います。 *Il y a un chat dans le jardin.* |
| goûts et capacités | にほんごが じょうずです。 *Il est doué en japonais.* |
| information nouvelle | あ、あめが ふっています。 *Tiens, il pleut.* |

## Les deux ensemble

ぞうは はなが ながいです。 *L'éléphant, son nez est long.*
Le thème (l'éléphant) est posé par は, le sujet de « long » (le nez) par が.

## Contraste avec は

は sert aussi à **opposer** : ce qui est dit vaut pour ce thème-là, pas forcément pour les autres.

- にくは たべます。でも さかなは たべません。 *La viande, j'en mange. Mais le poisson, non.*
- きょうは いそがしいです。 *Aujourd'hui (en tout cas), je suis occupé.*

C'est pourquoi は apparaît souvent dans les phrases **négatives** : コーヒーは のみません, « le café, je n'en bois pas » (sous-entendu : autre chose, peut-être).

## Question et réponse

Le mot qui répond à une question en が garde が dans la réponse :

- だれが きましたか。 → たなかさん**が** きました。 *C'est M. Tanaka qui est venu.*

Répondre avec は sonnerait faux : on ne parle pas d'un thème déjà connu, on **apporte** l'information demandée.

À l'inverse, une question en は reçoit une réponse en は : これは なんですか → それは ほんです.

## Dans une proposition subordonnée

À l'intérieur d'une proposition qui décrit un nom, on utilise **が**, jamais は :

- わたし**が** かいた ほん : *le livre que j'ai écrit.*
- ともだち**が** すんでいる まち : *la ville où vit mon ami.*

C'est une règle fiable qui simplifie beaucoup la lecture.

## Information connue ou nouvelle

- は présente quelque chose que l'interlocuteur **connaît déjà** ou peut identifier : むかしむかし、おじいさん**が** いました。おじいさん**は** やまへ いきました。 Le vieil homme apparaît d'abord avec が (nouveau), puis revient avec は (connu).

> **À retenir.** Dans le doute : は pour poser le décor, が pour répondre à « qui ? » ou « quoi ? ».
