Deux transformations du verbe : le **passif** (subir une action) et le **causatif** (faire faire). Combinées, elles donnent « être forcé de ».

## Le passif

| Groupe | Règle | Exemple |
| --- | --- | --- |
| 1 | *u* → *a* + れる | しかる → しかられる |
| 2 | る → られる | みる → みられる |
| irréguliers | | する → される, くる → こられる |

Pour les verbes en う, le *a* devient わ : かう → かわれる (passif), かわせる (causatif).

L'auteur de l'action est marqué par **に** : せんせいに ほめられました (j'ai été félicité par le prof).

## Le passif de désagrément

Spécificité japonaise : même un verbe sans objet peut se mettre au passif pour dire qu'on **en a souffert**.
- あめに ふられました。 *J'ai été pris par la pluie* (le verbe ふる, « tomber », n'a pas d'objet).
- でんしゃで となりの ひとに たばこを すわれました。 *Dans le train, mon voisin a fumé (et ça m'a gêné).*

## Le causatif

| Groupe | Règle | Exemple |
| --- | --- | --- |
| 1 | *u* → *a* + せる | まつ → またせる |
| 2 | る → させる | おきる → おきさせる |
| irréguliers | | する → させる, くる → こさせる |

- おまたせしました。 *Désolé de vous avoir fait attendre.* (formule figée, très courante)

> **À retenir.** Passif : je subis. Causatif : je fais faire. Causatif-passif : on me fait faire.
