Le keigo n'est pas qu'une question de politesse : il marque **la relation** entre les personnes. On élève l'autre (respect) ou on s'abaisse soi-même (humilité).

## Trois niveaux

| Type | Rôle | Exemple avec いく |
| --- | --- | --- |
| 丁寧語 poli | être courtois | いきます |
| 尊敬語 respect | élever l'autre (client, supérieur) | いらっしゃいます |
| 謙譲語 humble | s'abaisser, soi et son groupe | まいります |

## Les verbes spéciaux

| Verbe | Respect (l'autre) | Humble (moi) |
| --- | --- | --- |
| いる / いく / くる | いらっしゃる | おる / まいる |
| いう | おっしゃる | もうす |
| たべる / のむ | めしあがる | いただく |
| する | なさる | いたす |
| みる | ごらんになる | はいけんする |
| しる | ごぞんじだ | ぞんじる |

## Les formules du quotidien

- いらっしゃいませ。 *Bienvenue* (à l'entrée d'un magasin)
- しょうしょう おまちください。 *Veuillez patienter un instant.*
- よろしく おねがいいたします。 *Je compte sur vous.* (fin de mail ou de présentation)

> **À retenir.** Jamais de respect pour soi-même ni pour sa propre entreprise face à un client : on s'abaisse, on n'élève pas.
