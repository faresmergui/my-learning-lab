- q: Quand utiliser と ?
  a: 'Pour une **conséquence automatique** ou habituelle : はるに なると、さくらが さきます (quand vient le printemps, les cerisiers fleurissent).'
- q: Comment former ば ?
  a: 'Groupe 1 : *u* → *e* + ば (いく → **いけば**). Groupe 2 : る → **れば** (たべれば). Adjectifs en い : い → **ければ** (やすければ).'
- q: Quand utiliser ば ?
  a: 'Pour une **condition générale**, souvent pour conseiller : はやく ねれば、げんきに なります.'
- q: Quand utiliser たら ?
  a: 'Le plus polyvalent : « si » ou « une fois que ». Forme en た + ら : **いったら**, **やすかったら**. Seul à pouvoir être suivi d''un ordre ou d''un souhait dans tous les cas.'
- q: Quand utiliser なら ?
  a: '« **Si c''est le cas** » : on reprend ce que l''autre vient de dire. きょうとへ いくなら、きよみずでらが いいですよ.'
- q: Lequel choisir en cas de doute ?
  a: '**たら**. Il fonctionne dans la plupart des situations du quotidien.'

Le français n'a qu'un « si ». Le japonais en a quatre, avec des nuances. Bonne nouvelle : たら passe presque partout.

## Les quatre en un tableau

| | Formation | Nuance | Exemple |
| --- | --- | --- | --- |
| と | neutre + と | conséquence automatique | ボタンを おすと、ドアが あきます |
| ば | *e* + ば | condition générale, conseil | れんしゅうすれば、うまく なります |
| たら | た + ら | si, une fois que | あめが ふったら、いきません |
| なら | neutre + なら | si c'est le cas (ce que tu dis) | パソコンを かうなら、これが いい |

## Les pièges

- Après と, impossible de donner un ordre ou d'exprimer une volonté : ✗ うちに かえると、でんわして.
- ば est rarement suivi d'une demande quand le verbe principal est une action volontaire. Utilise たら.
- なら se base sur ce qui vient d'être dit, pas sur un enchaînement dans le temps.

> **À retenir.** Indication de chemin ou machine : と. Conseil général : ば. Tout le reste : たら.
