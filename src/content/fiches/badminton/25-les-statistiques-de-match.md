- q: Quelles sont les trois façons de finir un point ?
  a: Un **coup gagnant** (l'adversaire ne touche pas le volant ou ne peut pas le remettre), une **faute provoquée** (l'adversaire, sous pression, fait la faute) et une **faute directe** (faute sans pression particulière).
- q: Pourquoi compter ses fautes directes ?
  a: Parce qu'à ton niveau, une grande partie des points se perdent **sans que l'adversaire ait rien fait de spécial**. C'est souvent la statistique qui progresse le plus vite avec un peu d'attention.
- q: Quelle est la statistique la plus utile en double ?
  a: 'Le **point de départ** de chaque point perdu : service, retour, troisième volant, défense, attaque, filet. Elle montre **où** se perd le match, et donc quoi travailler.'
- q: Comment filmer un match simplement ?
  a: 'Un téléphone posé **en hauteur derrière le terrain**, dans l''axe, cadrant tout le terrain. Pas besoin de matériel spécial : l''important est de voir les deux paires et la trajectoire du volant.'
- q: Combien de matchs analyser pour tirer une conclusion ?
  a: Au moins **deux ou trois**. Un seul match peut être trompeur (un adversaire particulier, une mauvaise journée). Ce sont les **tendances** qui comptent.
- q: Qu'est-ce qu'un ratio gagnants / fautes directes ?
  a: Le rapport entre les points gagnés par un coup gagnant et les points perdus par faute directe. Il indique si le jeu est **trop risqué** (beaucoup de fautes) ou **trop passif** (peu de gagnants).

On a souvent une **impression** fausse de son propre match. On se souvient des beaux smashs et des points spectaculaires perdus, mais on oublie les petites fautes qui ont réellement coûté le set. Quelques statistiques simples, relevées sur vidéo, donnent une image plus juste.

## Comment se termine un point

Chaque point se termine de l'une de trois façons :

| Fin de point | Définition | Exemple |
| --- | --- | --- |
| **Coup gagnant** | l'adversaire ne peut pas remettre le volant | smash qui touche le sol, filet qui meurt |
| **Faute provoquée** | l'adversaire fait la faute sous pression | défense qui sort après un smash au corps |
| **Faute directe** | faute sans pression particulière | dégagement dehors, service dans le filet, filet facile manqué |

À ton niveau, les **fautes directes** représentent souvent une grande part des points perdus. C'est la première chose à compter.

## Filmer un match

Pas besoin de matériel professionnel :

- un **téléphone** posé en hauteur, derrière le terrain, dans l'axe ;
- tout le terrain dans le cadre, et si possible un peu d'espace au-dessus pour voir les trajectoires ;
- vérifier la batterie et la place de stockage avant le match.

## Une feuille de relevé simple

Pour chaque point perdu, noter deux choses : **comment** il s'est terminé, et **où** il a commencé à mal tourner.

| Phase où le point se perd | Faute directe | Faute provoquée | Gagnant adverse |
| --- | --- | --- | --- |
| Service | | | |
| Retour de service | | | |
| Troisième volant | | | |
| Défense | | | |
| Attaque | | | |
| Filet | | | |

Faire de même pour les points gagnés donne une image complète, mais commencer par les points perdus est déjà très instructif.

## Lire les résultats

| Constat | Interprétation probable | Piste de travail |
| --- | --- | --- |
| Beaucoup de fautes directes en fond | prise de risque excessive ou fatigue | plus de marge, travail physique |
| Beaucoup de points perdus au retour | retour mal maîtrisé | cibles et position au retour |
| Beaucoup de gagnants adverses en attaque | trop de volants d'attaque donnés | lifts et dégagements plus hauts et plus longs |
| Peu de gagnants de ton côté | jeu trop passif | chercher l'attaque plus tôt |
| Points perdus au milieu | hésitation dans la paire | règle du milieu à fixer |

## Le ratio gagnants / fautes directes

Le rapport entre tes coups gagnants et tes fautes directes donne une idée de ton **équilibre risque / sécurité** :

- **beaucoup de fautes, peu de gagnants** : jeu trop risqué ;
- **peu de fautes, peu de gagnants** : jeu trop passif, l'adversaire n'est jamais mis en difficulté ;
- **l'idéal** : assez de gagnants pour mettre la pression, sans offrir de points.

## En double

En double, noter aussi **qui** était impliqué dans le point (toi ou ton partenaire) et dans quelle **formation** (attaque ou défense). Cela permet de voir :

- si les points se perdent surtout dans une **phase** (souvent les transitions) ;
- si un adversaire est **ciblé** systématiquement ;
- si la paire perd des points sur des volants **entre les deux**.

L'objectif n'est pas de désigner un responsable, mais de savoir quoi travailler ensemble.

## Les limites

- Un seul match peut tromper : il faut **plusieurs matchs** pour voir une tendance.
- Trop de statistiques tue l'analyse : **deux ou trois** indicateurs suffisent.
- Les chiffres ne disent pas **pourquoi** : la vidéo sert ensuite à comprendre la cause (placement, choix de coup, fatigue).

> **À retenir.** Classe chaque point : gagnant, faute provoquée ou faute directe. Note dans quelle phase il se perd. Filme avec un téléphone derrière le terrain. Suis deux ou trois indicateurs sur plusieurs matchs, puis utilise la vidéo pour comprendre les causes.
